# Kalvium Community Cross-Fork Pull Request & Submission Guide

This guide explains how your code on **`Abhiram453/Autorag_champs`** is submitted to the **`kalviumcommunity/Autorag_champs`** organization repository via GitHub Cross-Fork Pull Requests (PRs).

---

## 💡 How GitHub Fork Workflows Work

1. **Development & Pushes**: You push your feature branches (`feature/<assignment-name>`) to your personal repository: `https://github.com/Abhiram453/Autorag_champs`.
2. **Pull Requests (PRs)**: You open a Pull Request targeting the upstream organization: `kalviumcommunity/Autorag_champs:main`.
3. **Evaluation**: Kalvium automated evaluators and mentors review and grade your PR on the `kalviumcommunity` repository!
